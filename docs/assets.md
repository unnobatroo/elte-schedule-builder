For new documentation images:

1. Capture only project UI using DEMO data.
2. Remove usernames, real subject selections, share links, and other personal
   information.
3. Store the image in a documented repository asset folder.
4. Record the creator and license in this file.

Replacing the external screenshots with newly captured, repository-owned DEMO
screenshots would remove the Imgur runtime dependency and close the remaining
provenance question.
